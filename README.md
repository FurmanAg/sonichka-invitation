# Романтичне запрошення для Сонічки ♡

Ніжна інтерактивна листівка на React + Vite з власним календарем, вибором часу, анімаціями, блискітками за курсором і захищеним надсиланням листа через Express + Resend.

## Що вже реалізовано

- Плавні переходи між чотирма екранами на Framer Motion.
- Три прикріплені зображення в `public/images/`; основний Пушин розташований по центру стартової та фінальної композицій. У `src/components/Pusheen.jsx` є чітка позначка, де замінити файли на інші.
- Кнопка «НІ 🙈», яка тікає, та святковий вибух сердечок для «ТАК ❤️».
- Календар українською без `<input type="date">`: минулі дні вимкнені, поточний день позначений, місяці перемикаються.
- Вибір запропонованого або довільного часу, автоматичний український підсумок дати.
- Рожевий слід із частинок для миші та дотику; ефекти не блокують кнопки.
- Відправлення лише після натискання підтвердження, блокування дублювання, idempotency key Resend та екран помилки з повторною спробою.
- API-ключ Resend існує лише на Node.js сервері, а `.env` виключений із Git.

## Швидкий запуск

1. У корені проєкту створіть свій локальний файл налаштувань:

   ```powershell
   Copy-Item .env.example .env
   ```

2. Відредагуйте `.env`:

   ```dotenv
   EMAIL_TO=joneswield@gmail.com
   EMAIL_FROM=Your Name <your-verified-address@example.com>
   RESEND_API_KEY=re_ваш_ключ
   FRONTEND_ORIGIN=http://localhost:5173
   ```

3. Запустіть frontend і backend однією командою:

   ```powershell
   npm run dev:all
   ```

4. Відкрийте [http://localhost:5173](http://localhost:5173).

Окремі команди: `npm run dev` запускає Vite, `npm run server` запускає API на порту `8787`, а `npm run build` створює production-бандл у `dist/`.

## Налаштування Resend

1. Створіть обліковий запис у [Resend](https://resend.com/) та відкрийте **API Keys**.
2. Створіть ключ для сервера й додайте його лише до `.env` як `RESEND_API_KEY`.
3. У Resend верифікуйте домен або адресу відправника. Саме цю верифіковану адресу задайте в `EMAIL_FROM` (наприклад, `Ваше ім’я <hello@yourdomain.com>`).
4. Для тестування Resend може дозволяти власну адресу в `EMAIL_TO`; для надсилання на інші адреси зазвичай потрібен верифікований домен.

Сервер сам перевіряє дату й час, обчислює день тижня, а потім відправляє лист з темою `❤️ Сонічка погодилась на зустріч!`. Без коректних налаштувань API повертає помилку — інтерфейс не показує фальшивого успіху.

## Розгортання

Найпростіший поділ: frontend на Vercel або Netlify, backend на Render або Railway.

1. Розгорніть репозиторій як Node-сервіс. Команда запуску: `npm run server`.
2. У налаштуваннях бекенду внесіть `EMAIL_TO`, `EMAIL_FROM`, `RESEND_API_KEY` та `FRONTEND_ORIGIN=https://ваш-фронтенд.example`.
3. Розгорніть frontend командою збірки `npm run build`, директорія публікації — `dist`.
4. У середовищі frontend додайте `VITE_API_URL=https://адреса-вашого-api.example`, потім перебудуйте frontend.
5. Оновіть `FRONTEND_ORIGIN` у backend до остаточної адреси frontend.

Ніколи не додавайте `.env` або `RESEND_API_KEY` до репозиторію.
